# connected.cls v2.3.0: רשימת פקודות

התבנית מסבירה את עצמה: לכל פקודה יש מטרה אחת. השתמשו רק בפקודות שברשימה.

## פרטי המסמך (בהקדמה)
| פקודה | מטרה |
|-------|------|
| `\booktitle{}` | שם הספר: בשער ובבאנר |
| `\booksubtitle{}` | כותרת משנה בשער |
| `\englishtitle{}` | הכותרת באנגלית בשער |
| `\bookauthors{}` | מחברים: בשער ובשורה התחתונה |
| `\groupcode{}` | קוד הקבוצה (8 תווים): בשורה התחתונה |
| `\course{}` | שם הקורס: בשער |
| `\makecover` | בונה את עמוד השער |
| `\keywords{}` | שורת מילות מפתח בסוף התקציר |

## עברית ואנגלית
| פקודה | מטרה | דוגמה |
|-------|------|-------|
| `\en{}` | מילה או ביטוי באנגלית כיחידה LTR אחת | `\en{Azure OpenAI Service}` |
| `\num{}` | מספר, טווח, אחוז, תאריך או גרסה כיחידה LTR אחת | `\num{2005--2024}`, `\num{72.3\%}` |
| `\mathheb{}` | עברית בתוך נוסחה | `$P(\mathheb{רווחה})$` |
| `\heb{}` | עברית בתוך צומת TikZ | `\node{\heb{טריגר}};` |

## תיבות (מסגרת LTR, תוכן עברי)
| סביבה | צבע | שימוש |
|-------|-----|-------|
| `thinkbox[כותרת]` | צהוב | שאלה למחשבה |
| `factbox[כותרת]` | טורקיז | נתון מפתח |
| `alertbox[כותרת]` | אלמוג | אזהרה |
| `tipbox[כותרת]` | ירוק | טיפ לאיזון |
| `eqbox[כותרת]` | כחול-לילה | משוואה מודגשת |
| `epigraph{מחבר, שנה}` | אפור | ציטוט או מחשבה פותחת. ארגומנט ריק מסתיר את הקו |

## איורים, רשימות וקוד
| פקודה | מטרה |
|-------|------|
| `ltrpicture[opts]` | תרשים TikZ בטוח לכיוון |
| `checklist` | רשימת תיוג עם ☐ ירוק |
| `\pythonfile[firstline=a,lastline=b]{file}{כותרת}` | תיבת קוד Python ממקור אמיתי. מ-v2.4.0 הטווח נחתך ב-`connected.lua` (חייב לשכון ליד `connected.cls`), ומספרי השורות הם האמיתיים |
| `\Needspace{6\baselineskip}` | לפני פסקת הקדמה לרשימה: מונע שורת הקדמה בודדת בתחתית עמוד (v2.4.0) |
| `\caption[קצר]{ארוך}` | בכל איור: הכיתוב הקצר הוא מה שמופיע ברשימת האיורים (v2.4.0) |

## ציטוטים (IEEE)
| פקודה | מטרה |
|-------|------|
| `\parencite{key}` | ‎[1]‎, יחידה אנגלית שאינה נשברת |
| `\textcite{key}` | ‎Author [1]‎ |
