# qa-img: figures and captions

## Automatic part
`python qa/qa_check.py img` checks that every figure label is referenced and every `\includegraphics` file exists. It also catches "float too large" warnings.

## Visual part: the four rules for every figure (course guide, §16.6)
1. It has a Hebrew caption that says what we see.
2. It has a number, and that number is mentioned in the text.
3. Text inside it is readable when printed, and no label overlaps another.
4. Colors are consistent: the same meaning gets the same color across the whole book.

## Also check
- The figure appears on the same page as its first reference, or the next page.
- No figure sits alone on a nearly empty page.
- Nothing touches the page edge or the margin.
- **Sources:** every image is generated by code (Python or TikZ). Images from the internet with copyright are not allowed. List each image and the script that makes it.

## Where fixes belong
- Size or placement policy → template or `\includegraphics` width in the figure wrapper
- Content of a graph → `python/make_graphs.py` or `python/make_images.py`. Never edit the PNG by hand.
